## מה זה

אפליקציית ווב בעברית (RTL) לניהול תיק לקוחות של מנהל מכירות, שנבנתה משני
דוחות PDF של ה-ERP. **בלי שרת, בלי build, בלי תלויות בזמן טעינה** — HTML, CSS
ו-JavaScript בלבד. הנתונים חיים ב-localStorage ונטענים בפעם הראשונה מקובץ
זינוך שנבנה מה-PDF.

```
web/
  index.html        המעטפת
  css/app.css       מערכת העיצוב (אסימוני oklch, יום/לילה)
  js/config.js      שם, סניף, מפתחות אחסון
  js/format.js      פורמט מספרים ותאריכים
  js/ui.js          אייקוני SVG ורכיבים חוזרים
  js/store.js       שכבת הנתונים + היסטוריית ביטול
  js/metrics.js     חישובי הניתוח + catalog() לסיווג
  js/charts.js      גרפי SVG ללא ספריות
  js/assistant.js   מנוע השאילתות של הצ'אט
  js/excel.js       ייצוא/ייבוא
  js/views/         dashboard, customers, grid, activity, settings
  js/app.js         ניווט, נושא, מגירה, צ'אט, חיפוש מהיר
  data/dataset.js   נתוני הזינוך — נוצר אוטומטית, לא לערוך ביד
tools/
  parse_pdf.py      פענוח ה-PDF ממיקומי התווים
  build_dataset.py  בונה את dataset.js / dataset.json
```

עדכון מדוח חדש: `python3 tools/build_dataset.py <תיקיית ה-PDF>` (דורש `pymupdf`).

## עובדות על הנתונים — לא לשנות בלי לבדוק מחדש

הפענוח הוצלב מול הדוח עצמו, ואלה המספרים הקובעים:

- **2025: 16,203,057.74 ₪ · 2026 (ינואר–ספטמבר): 11,228,824.09 ₪**
- כל 21 סכומי החודשים תואמים לאגורה.
- ארבעת סיכומי הסוכנים שהדוח מדפיס תואמים: בני ויסמן 10,731,247.72 /
  אייל בן אבי 5,376,062.89 / שוקי צוקרון 38,312.23 / דני חיים 57,434.90 (2025).
- שורת "סה"כ כללי" של הדוח נשמרת בתוך `dataset.js` תחת `control`, ומסך
  "נתונים וקבצים" מצליב מולה חודש-חודש. **אם מסך ההצלבה מפסיק להראות
  "תואם לאגורה" — משהו נשבר.** זו בדיקת האמת המהירה ביותר.

### שלושה סיווגים שהדוח לא אומר במפורש
1. **`20289001` "לקוחות שונים" הוא סל מרוכז, לא חברה.** המחזור שלו נספר
   בסיכומים אבל הוא מוחרג מדירוגים ומרשימות הפעולה.
2. **מספר לקוח שהוא קידומת מדויקת של אחר הוא חשבון אב**, והארוך ממנו אתר
   שלו. ארבעה זוגות (למשל קרגל משמר השרון / משמר דוד). זה **לא** באג פענוח —
   נבדק מול מיקומי התווים ב-PDF.
3. **12 גופים מופיעים רק כמשלמים** ולא כיעד משלוח; הם אינם לקוחות בתיק.

הכול מרוכז ב-`Metrics.catalog()`.

## מלכודות — דברים שנשברו פעם וכבר תוקנו

| הנחה מפתה | למה היא שוגה |
|---|---|
| מפתח תנועת מכירה = לקוח+משלם+שנה+חודש | **הסוכן חלק מהמפתח.** אותו צמד מופיע באותו חודש אצל שני סוכנים ב-10 מקרים; בלי הסוכן נעלמים 16,186 ₪ בשקט |
| `Intl.NumberFormat` עם `style:"currency"` | מחדיר תווי כיוון נסתרים לתוך הספרות (`‏11,228,824 ‏₪`). מפרמטים מספר ומוסיפים ` ₪` ידנית |
| מספר עם סימן מסתדר לבד ב-RTL | המינוס קופץ לקצה השני. `.delta` ו-`.num` חייבים `direction: ltr` |
| `inset-inline-end` = ימין | בעברית זה **שמאל**. זה מה שפתח את הסרגל הנייד מהצד ההפוך |
| אפשר להציג בתא הגיליון מספר מעוגל | התא מציג מעוצב במנוחה ומחליף לגולמי ב-focus, אחרת יציאה מתא משנה נתונים |
| שחור מוחלט למצב לילה | על `#000` טקסט לבן בוהק והמשטחים מאבדים עומק. הרקע הוא `#12151b` |
| `tabular-nums` על המספר הגדול | בגודל תצוגה `121` נראה רופף. ספרות טבלאיות רק בטורים ובצירים |
| שם קובץ הורדה בעברית | כרומיום מתעלם ושומר "download" בלי סיומת. שם הייצוא באנגלית בכוונה |

## הצ'אט — העיקרון שאסור לשבור

`assistant.js` הוא **מנוע שאילתות דטרמיניסטי, לא מודל שפה, ובלי גישה לרשת.**
כל מספר בתשובה נשלף מ-`Metrics`/`Store`. המשמעות: הוא לא יכול להמציא נתון,
וכשאין כיסוי לשאלה הוא אומר "לא הצלחתי לפענח" ומציע שאלות שיש להן תשובה.

**אם מחליפים אותו במודל שפה — צריך אישור מפורש של המשתמש.** הוא ביקש
במפורש שלא יהיו נתונים סינתטיים.

זיהוי שם לקוח מתעלם ממילים גנריות (`GENERIC` ב-`assistant.js`), אחרת
"מי הלקוחות הגדולים?" נתפס כשאלה על החברה ששמה "לקוחות שונים". כוונות רשימה
נבדקות **לפני** זיהוי שם לקוח — הסדר ב-`RULES` משמעותי.

## עיצוב

- **טיפוגרפיה:** Heebo. **צבע:** oklch, מותג אחד + שני צבעים סמנטיים.
- **נושא:** העדפה `auto|light|dark` ב-localStorage; רק התוצאה נחתמת כ-`data-theme`
  על ה-HTML. נקודת אמת אחת לצבעים.
- **גרפים** לפי מתודולוגיית `dataviz`: השוואה לאשתקד = הדגשה (צבע מול אפור),
  שינוי = קוטביות, פילוח סוכנים = זהות (שלושה גוונים **מאומתים** —
  `node scripts/validate_palette.js "#3987e5,#d95926,#199e70" --mode dark --surface "#12151b" --pairs all`).
  לכל גרף יש תצוגת טבלה. שינוי צבעים מחייב הרצה מחדש של המאמת.
- **נייד:** מתחת ל-1000px סרגל תחתון, טבלאות כ-כרטיסים (`cards-on-mobile`),
  גיליונות מסך מלא, שטחי נגיעה 55px, קלט 16px.

## איך בודקים

```bash
cd web && python3 -m http.server 8765
```

סקריפטי הבדיקה בסקראצ'פאד (`beny.js`, `verify.js`, `func.js`) מריצים כרומיום:
```bash
node beny.js <out-dir>     # נייד, צ'אט, נושא
node verify.js <out-dir>   # סיווג, הצלבה, תצוגות טבלה
node func.js <out-dir>     # עריכת גיליון, ביטול, שמירה אחרי רענון
```
כרומיום ב-`/opt/pw-browsers/chromium-1194/chrome-linux/chrome`.

**מגבלות הסביבה:** Google Fonts ו-cdnjs חסומים — בצילומי מסך מהסביבה יופיע
גופן ברירת מחדל, ומסלול ה-xlsx נופל לגיבוי Excel XML. אצל המשתמש שניהם עובדים.
`vercel.app` חסום מהסביבה; לאימות הפריסה משתמשים בכלי ה-Vercel MCP
(`web_fetch_vercel_url`), לא ב-curl.
