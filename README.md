# BENY · ניהול מכירות

אפליקציית ווב בעברית לניהול תיק הלקוחות של מנהל מכירות, שנבנתה מחמישה דוחות
"ניתוח מכירות (ת.משלוח) — מחירים" — 2022 עד 2026. עובדת בטלפון כמו אפליקציה
ובמחשב כמו מערכת. האפיון המלא: [`docs/SPEC.md`](docs/SPEC.md).

## הפעלה

```bash
cd web && python3 -m http.server 8000
```

ואז לפתוח <http://localhost:8000>. זהו — אין התקנה, אין שרת ואין חשבון:
המערכת עובדת מיד עם נתוני הדוחות, והנתונים נשמרים בדפדפן. אפשר גם להעלות
את תיקיית `web/` לכל אחסון סטטי.

## העוזר

כפתור השיחה בכותרת פותח עוזר ששולף תשובות מהנתונים: "כמה מכרנו השנה?",
"מי דורש טיפול?", "מה המגמה בחמש השנים?", "כמה מכרנו ב-2022 לעומת 2025?",
"מה התחזית לסוף השנה?".

הוא **אינו מודל שפה ואין לו גישה לרשת** — הוא מנוע שאילתות שרץ על אותם
חישובים שמזינים את המסכים. לכן הוא לא יכול להמציא מספר, וגם לא יכול לענות
על שאלה שאין לה כיסוי בנתונים: במקרה כזה הוא אומר שלא הבין ומציע שאלות
שכן יש להן תשובה.

## קיצורי מקלדת

| | |
|---|---|
| `Ctrl/⌘ + K` או `/` | חיפוש לקוח מכל מקום |
| `Ctrl/⌘ + Z` | ביטול השינוי האחרון |
| חצים | ניווט בין תאים בטבלת החודשים |
| `Esc` | סגירת חלון או ביטול עריכה |

## עדכון מדוח חדש

```bash
pip install pymupdf
python3 tools/build_dataset.py <תיקיית ה-PDF>
```

הסקריפט בונה מחדש את `web/data/dataset.js`. הוא מזהה את מבנה הטבלה
מהכותרות ואת השנה משורת התקופה של הדוח, ולכן עובד גם על דוח עם מספר חודשים
אחר — ואפשר להריץ אותו על דוח בודד: שנה שכבר במאגר ואין לה PDF נשמרת כמו
שהיא.

במכשיר שכבר מחזיק נתונים, הדוח החדש מחליף רק את שורות ה-ERP. עריכות ידניות,
יעדים, פרטי לקוחות ורישומי פעילות נשארים.

## מבנה הפרויקט

```
web/
  css/app.css       מערכת העיצוב: אסימוני צבע ב-oklch, בהיר וכהה
  js/store.js       שכבת הנתונים, כולל היסטוריית ביטול
  js/metrics.js     חישובי הניתוח (השוואה לתקופה מקבילה, סיכון, תחזית)
  js/charts.js      גרפי SVG ללא ספריות, קוראים צבע מהנושא הפעיל
  js/excel.js       ייצוא וייבוא
  js/ui.js          אייקונים ורכיבים חוזרים
  js/views/         המסכים (בית, מגמה, לקוחות, משימות, טבלת חודשים, נתונים)
  data/dataset.js   נתוני הדוחות בקידוד דחוס
tools/              פענוח ה-PDF ובניית מאגר הנתונים
```

## בקרת נכונות הנתונים

הפענוח מצטלב מול סיכומי הדוח עצמו: כל 57 החודשים, הסכום הכולל של כל שנה, וכל
סיכום סוכן שהדוח מדפיס — תואמים לאגורה.

| שנה | מחזור |
|---|---|
| 2022 | ‎15,483,017.74 ₪ |
| 2023 | ‎18,441,363.69 ₪ |
| 2024 | ‎16,183,215.31 ₪ |
| 2025 | ‎16,203,057.74 ₪ |
| 2026 (ינואר–ספטמבר) | ‎11,228,824.09 ₪ |

מסך "נתונים וקבצים" מציג את ההצלבה חודש-חודש לכל שנה, ומסמן גם את שבע
השורות שהדוח תמחר ביורו ואת ספטמבר 2026 שהדוח תפס באמצעו.
