# מערכת ניהול מכירות · גדות מסופים

אפליקציית ווב בעברית לניהול תיק הלקוחות של מנהל מכירות, שנבנתה מדוחות
"ניתוח מכירות (ת.משלוח) — מחירים" של 2025 ו-2026.
האפיון המלא: [`docs/SPEC.md`](docs/SPEC.md).

## הפעלה

```bash
cd web && python3 -m http.server 8000
```

ואז לפתוח <http://localhost:8000>. זהו — המערכת עובדת מיד עם נתוני הדוחות,
בלי התקנה ובלי שרת. הנתונים נשמרים בדפדפן.

אפשר גם לפתוח את `web/index.html` ישירות, או להעלות את תיקיית `web/`
לכל אחסון סטטי.

## חיבור ל-Supabase (אופציונלי)

בלי חיבור הכול נשמר במחשב אחד. עם חיבור הנתונים בענן וזמינים מכל מכשיר:

1. להריץ בעורך ה-SQL של הפרויקט את `db/schema.sql` ואחריו `db/seed.sql`.
2. ליצור דלי אחסון בשם `exports` (לעותק האקסל המתעדכן).
3. במסך "הגדרות וסנכרון" למלא Project URL ו-anon key וללחוץ על התחברות.

לקביעת החיבור מראש לכל המשתמשים אפשר למלא אותו ב-`web/js/config.js`.

## עדכון מדוח חדש

```bash
pip install pymupdf
python3 tools/build_dataset.py <תיקיית ה-PDF>
```

הסקריפט בונה מחדש את `web/data/dataset.js` ואת `db/seed.sql`. הוא מזהה את
מבנה הטבלה מהכותרות, ולכן עובד גם על דוח עם מספר חודשים אחר.

## מבנה הפרויקט

```
web/            האפליקציה: HTML, CSS, JavaScript, ונתוני הזינוך
  js/store.js     שכבת הנתונים - מקומי או Supabase, API אחד לשניהם
  js/metrics.js   חישובי הניתוח (השוואה לתקופה מקבילה, סיכון, תחזית)
  js/charts.js    גרפי SVG ללא ספריות חיצוניות
  js/excel.js     ייצוא, ייבוא, ועדכון הקובץ בענן
  js/views/       המסכים
db/             סכמת Postgres ונתוני זינוך ל-Supabase
tools/          פענוח ה-PDF ובניית מאגר הנתונים
```
